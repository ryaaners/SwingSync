Reproduction: run `.venv/bin/python -m pytest tests/test_serve_local.py -q -p no:cacheprovider` with local socket permission; the initial run yielded40passed/2failed, including the valid-listener case. Resolution uses Darwin's public TCP_CONNECTION_INFO first-byte LISTEN state and the normal SO_ACCEPTCONN check elsewhere. Independent rerun accepted the actual valid listener, retained caller descriptor ownership, and rejected external/non-listening/UDP/Unix/file/closed/malformed descriptors. Both platform branches are covered; Linux execution belongs to CI.

2. **P2 — Unix negative test exceeded macOS socket-path limit (resolved).** The initial test bound AF_UNIX to pytest's long default temporary path and failed before exercising validation. Same reproduction command failed with `AF_UNIX path too long`. Resolution uses a socket pair; independent final rerun passes without changing pytest's temporary root.

3. **P2 — replacing the entire public directory could rebase static containment (resolved).** Worker self-review reproduced200/private content after renaming the original build and replacing its path with a symlink to another directory. A pinned initial public-root guard now rejects a symlink/changed root and paths outside the original root. Independent regression rerun verifies404 and the API remains operational. File symlinks, traversal attempts, public/private directory overlap and unknown API routes are also covered. This does not claim a filesystem-privileged adversarial mutation boundary beyond the tested local serving behavior.

4. **P2 — incomplete source provenance (resolved).** Initial demo fingerprinting omitted imported proposal_handoff and movement dependencies, allowing those source changes to evade `_unchanged`. Resolution fingerprints the complete backend Python source set plus both launchers, pyproject and uv.lock, comparing paths as well as hashes. The regression changes a previously omitted dependency fingerprint and verifies refusal. Source, frontend, fixture and generated output hashes are rechecked before and after completed-ledger publication.

5. **P2 — child exit during shutdown could skip explicit cleanup (resolved).** Initial poll→killpg had an ESRCH race; a child exiting after poll could raise ProcessLookupError before listener close and stopped-attempt recording. Resolution tolerates the already-exited group, waits/reaps, and uses nested finally blocks for parent socket closure and cleanup state. The regression injects ProcessLookupError and verifies reaping. Deliberate failure after startup produces a failed ledger, no report, and a stopped owned child.
